## USER ROLES AND ACCESS

The app has 4 user roles managed via Supabase Auth + a `profiles` table with a `role` column:

1. **free_user** — signed up with email, no payment
2. **investment_client** — existing advisory client, manually activated by admin
3. **advisor** — firm team member, manages assigned investment clients only
4. **super_admin** — full access to all users, all data, all settings

Each role sees a completely different UI. Use a `role` field in the `profiles` table to route users to the correct portal after login.

**RLS Policies — apply these after creating tables:**

```sql
-- Profiles: users see only their own row; admins see all
ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
CREATE POLICY "users_own_profile" ON profiles FOR ALL TO authenticated
  USING (id = auth.uid());
CREATE POLICY "admins_all_profiles" ON profiles FOR ALL TO authenticated
  USING (EXISTS (SELECT 1 FROM profiles WHERE id = auth.uid() AND role IN ('advisor','super_admin')));

-- All user data tables: same pattern — own data only, advisors see assigned clients
ALTER TABLE budget_entries ENABLE ROW LEVEL SECURITY;
CREATE POLICY "own_budget" ON budget_entries FOR ALL TO authenticated USING (user_id = auth.uid());

ALTER TABLE financial_goals ENABLE ROW LEVEL SECURITY;
CREATE POLICY "own_goals" ON financial_goals FOR ALL TO authenticated USING (user_id = auth.uid());
CREATE POLICY "advisor_client_goals" ON financial_goals FOR ALL TO authenticated
  USING (EXISTS (SELECT 1 FROM client_profiles cp JOIN profiles p ON p.id = auth.uid()
    WHERE cp.user_id = financial_goals.user_id AND cp.advisor_id = auth.uid() AND p.role IN ('advisor','super_admin')));

ALTER TABLE net_worth_snapshots ENABLE ROW LEVEL SECURITY;
CREATE POLICY "own_nw" ON net_worth_snapshots FOR ALL TO authenticated USING (user_id = auth.uid());

ALTER TABLE assets ENABLE ROW LEVEL SECURITY;
CREATE POLICY "own_assets" ON assets FOR ALL TO authenticated USING (user_id = auth.uid());

ALTER TABLE liabilities ENABLE ROW LEVEL SECURITY;
CREATE POLICY "own_liabilities" ON liabilities FOR ALL TO authenticated USING (user_id = auth.uid());

ALTER TABLE portfolio_holdings ENABLE ROW LEVEL SECURITY;
CREATE POLICY "own_portfolio" ON portfolio_holdings FOR ALL TO authenticated USING (user_id = auth.uid());

ALTER TABLE health_scores ENABLE ROW LEVEL SECURITY;
CREATE POLICY "own_scores" ON health_scores FOR ALL TO authenticated USING (user_id = auth.uid());

ALTER TABLE client_profiles ENABLE ROW LEVEL SECURITY;
CREATE POLICY "own_client_profile" ON client_profiles FOR ALL TO authenticated USING (user_id = auth.uid());
CREATE POLICY "advisor_client_profiles" ON client_profiles FOR ALL TO authenticated
  USING (advisor_id = auth.uid() OR EXISTS (SELECT 1 FROM profiles WHERE id = auth.uid() AND role = 'super_admin'));

ALTER TABLE kyc_documents ENABLE ROW LEVEL SECURITY;
CREATE POLICY "own_kyc" ON kyc_documents FOR ALL TO authenticated USING (user_id = auth.uid());

ALTER TABLE financial_plans ENABLE ROW LEVEL SECURITY;
CREATE POLICY "client_own_plan" ON financial_plans FOR SELECT TO authenticated USING (client_id = auth.uid());
CREATE POLICY "advisor_manage_plans" ON financial_plans FOR ALL TO authenticated
  USING (advisor_id = auth.uid() OR EXISTS (SELECT 1 FROM profiles WHERE id = auth.uid() AND role = 'super_admin'));

ALTER TABLE documents ENABLE ROW LEVEL SECURITY;
CREATE POLICY "own_documents" ON documents FOR ALL TO authenticated USING (user_id = auth.uid());

ALTER TABLE conversations ENABLE ROW LEVEL SECURITY;
CREATE POLICY "conversation_parties" ON conversations FOR ALL TO authenticated
  USING (client_id = auth.uid() OR advisor_id = auth.uid());

ALTER TABLE messages ENABLE ROW LEVEL SECURITY;
CREATE POLICY "conversation_members_messages" ON messages FOR ALL TO authenticated
  USING (EXISTS (SELECT 1 FROM conversations c WHERE c.id = messages.conversation_id
    AND (c.client_id = auth.uid() OR c.advisor_id = auth.uid())));

ALTER TABLE advisor_tasks ENABLE ROW LEVEL SECURITY;
CREATE POLICY "advisor_own_tasks" ON advisor_tasks FOR ALL TO authenticated
  USING (advisor_id = auth.uid() OR EXISTS (SELECT 1 FROM profiles WHERE id = auth.uid() AND role = 'super_admin'));

ALTER TABLE leads ENABLE ROW LEVEL SECURITY;
CREATE POLICY "advisors_see_leads" ON leads FOR ALL TO authenticated
  USING (EXISTS (SELECT 1 FROM profiles WHERE id = auth.uid() AND role IN ('advisor','super_admin')));

ALTER TABLE blog_posts ENABLE ROW LEVEL SECURITY;
CREATE POLICY "published_posts_public" ON blog_posts FOR SELECT USING (status = 'published');
CREATE POLICY "admins_manage_posts" ON blog_posts FOR ALL TO authenticated
  USING (EXISTS (SELECT 1 FROM profiles WHERE id = auth.uid() AND role IN ('advisor','super_admin')));
```

## KEY BEHAVIOURS

1. **Auto-save**: All pathway forms auto-save to Supabase on field blur with a 500ms debounce. Show "Saving..." → "Saved ✓" indicator.

2. **Currency conversion**: Use a fixed rate (1 USD = 25,000 VND) for display purposes. When user switches currency toggle, multiply/divide all displayed values. Store all values in USD in Supabase.

3. **Role guard**: Wrap all protected routes in an AuthGuard component that checks the user's role. Wrong role → redirect to correct portal.

4. **Empty states**: Every data-dependent section must have a well-designed empty state with an icon, message, and action button. Never show blank white space.

5. **Loading states**: Every data fetch must show a skeleton loader (use Tailwind animate-pulse gray rectangles) while loading. Never show blank sections.

6. **Error handling**: Wrap all Supabase operations in try/catch. Show toast notifications (top-right) for success and error states. Use a consistent toast component.

7. **Realtime messages**: Use Supabase Realtime to subscribe to new messages in the active conversation. Update the chat UI instantly without refresh.

8. **Responsive tables**: All data tables must be horizontally scrollable on mobile. Use overflow-x-auto wrapper.

9. **Pathway progress persistence**: When a user leaves mid-pathway and returns, automatically restore their progress and jump to the last incomplete step.

10. **Smart upgrade prompt logic**: Calculate these conditions from user data and show SmartUpgradePrompt only when true:
    - savings_rate < 15% AND user has completed budget step
    - goals count = 1 (free tier limit reached)
    - pathway complete but no advisor booking
